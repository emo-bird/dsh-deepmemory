# dsh-deepmemory

[![](https://img.shields.io/badge/powered_by-dsh-4D6BFE?style=flat-square&logo=deepseek&logoColor=white)](https://github.com/deepseek-ai/deepseek-harness)

给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的**深度记忆**插件：让它在下一个会话里还记得你。

零服务、零账号、零网络——所有东西就一个本地 SQLite 文件。

## 它解决什么

普通会话的记忆只有上下文窗口那么长。窗口一关，上周一起调过的东西、你的口味、你家猫的名字，全没了。

装上这个插件，它会把「换个会话还用得上」的东西存下来，然后在下一轮对话里用一句很短的话告诉模型「你有记忆，去哪查」。**内容本身不会每轮塞进上下文**，模型需要时自己调工具取——所以注入成本是常数，不会越聊越贵。

## 你能得到什么

**三种记忆，各管一件事**

| | 是什么 | 什么时候用得上 |
|---|---|---|
| **事实** | 一句长期有效的话，比如「他住在杭州」「这个项目用 pnpm」 | 隔了一周还记得你的偏好 |
| **片段** | 双方说过的原话，按会话和日期存 | 想找回「我们当时是怎么决定的」 |
| **日记** | 每天一篇散文，由模型自己写，读起来像人记的 | 想知道「上个月我在忙什么」 |

事实和片段由模型在对话中主动写入；日记由定时任务每天自动写一篇，不用你操心。

**面板**——侧边栏一个图标，六个页签：

- **概览**：近一年的贡献墙（照 GitHub 那种排法）、最近日记、最近记忆
- **搜索**：三档检索，精确命中和「字形相近」用两种颜色分开标
- **记忆**：日历 + 目录树，点任意一天看当天的一切
- **事实**：唯一能手写内容的地方，增 / 删 / 筛
- **会话**：每个会话的记忆开关
- **设置**：每个预设的默认权限、写日记的人格、日界、嵌入模型

**按会话控制**——输入框右下角四个开关：读记忆 / 写记忆 / 计入日记 / 删除记忆。可以按预设配默认值，再按会话覆盖。关掉「读」之后，模型连 `memory_search` 这个工具都看不见。

**日记有两件别处没有的事**

- **日界是推出来的**，不是钉死在某一点。熬夜到凌晨两点那次不会被算进第二天，而是留在当天。（默认从最后一段连续活动推，可调空档阈值与最晚小时。）
- **夜尾巴**：第二天投递时先回头补前一天午夜之后那一段，补完自读一遍，比原来那篇更好才替换。

**不绑模型**——检索第一二档纯字面，零依赖零下载；第三档语义可选，装上本地 ONNX 模型后启用，调不通会自动降级，搜索不会整体失败。

## 安装

在 DSH 里：

```text
plugin_manager action=install_bundle target=git+https://github.com/emo-bird/dsh-deepmemory
```

然后重启 DSH。装好后侧边栏会出现图标，第一次打开面板就能用——数据存在 `${DSH_HOME:-~/.dsh}/deepmemory/memory.db`。

想装本地副本（改代码即时生效）：

```bash
git clone https://github.com/emo-bird/dsh-deepmemory
# 再把 profile 里的包做成指向这个目录的 junction/symlink
```

## 快速上手

装完什么都不用做。它会自动开始记。

想让它记住某件事，直接说：「记住，我的项目都在 D 盘」——模型会调 `memory_save`。

想让它翻旧账，直接问：「上次那个构建脚本叫什么来着」——模型会调 `memory_search`。

想调开关、改人格、配模型，点侧边栏图标进**设置**。

## 数据在哪

- `${DSH_HOME:-~/.dsh}/deepmemory/memory.db` — 事实、片段、日记、向量
- `${DSH_HOME:-~/.dsh}/deepmemory/settings.json` — 开关、人格、日界参数

会话日志才是真源，这个库随时可以从头重建。升级前会自动备份一份。
